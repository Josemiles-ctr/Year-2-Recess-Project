# Chest X-Ray Dataset Information

## Dataset Source
NIH Chest X-ray Dataset (NIH Clinical Center)

## Dataset Description
The dataset contains 112,120 chest X-ray images with associated disease labels.

## Dataset Organization
- train/normal: 48330 images
- train/abnormal: 41366 images
- val/normal: 6041 images
- val/abnormal: 5171 images
- test/normal: 6041 images
- test/abnormal: 5171 images

- Labels CSV: ..\data\raw\Data_Entry_2017.csv
- Metadata CSV: ..\data\raw\metadata.csv
